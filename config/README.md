# ปรับสมดุลเกม v6

แก้ไฟล์ game-balance.json ในโฟลเดอร์นี้ ตัวเลขเงินใช้บาท/ปี อัตราใช้ทศนิยม เช่น 0.12 = 12%

- dark: เงินเดือนสองสายมืด, ความร้อนที่เพิ่มต่อปี, โอกาสบุกค้นสูงสุด, น้ำหนักค่าสัมพันธ์ในการต่อรอง (0.45 = สัมพันธ์ 100 เพิ่มโอกาส 45 จุดเปอร์เซ็นต์ ก่อนจำกัดเพดาน 95%)
- family: อายุสิ้นสุดการเลี้ยงดู, ค่าเลี้ยงดูลูก, ค่าครองชีพพ่อแม่, อัตราเก็บเงิน, เงินตั้งต้น, โอกาสมรดก, ช่วงรายได้และเงินเก็บคู่ชีวิต, อายุเสียชีวิตพ่อแม่ และความเสี่ยงเสียชีวิตคู่ชีวิต
- assets: ราคาบ้าน/รถทุกแบบ, เงินดาวน์ ดอกเบี้ย ระยะผ่อน ค่าดูแล, โบนัสสุขภาพ/สุขรายปี, ค่าซ่อมเทียบราคาซื้อ และโอกาสข้อเสนอ/เสียหาย

โอกาสเหตุทรัพย์สินเป็นโอกาสในปีที่มีสิทธิ์ตรวจ: อายุ 18 ขึ้นไป ไม่อยู่ในคุก เว้นจากเหตุการณ์ล่าสุด 2 ปี และไม่มีเหตุสำคัญอื่นแทรก จึงไม่ใช่ความถี่รับประกันทุกปี

พ่อแม่ใช้รายได้หลังค่าครองชีพ จากนั้นเงินเก็บ เพื่อจ่ายค่าเลี้ยงดูจนตัวละครเริ่มงานครั้งแรก ส่วนขาดใช้เงินของลูกก่อน แล้วจึงลงหนี้ลูก หนี้วัยเด็กยังไม่คิดดอกเบี้ย/ทวงชำระจนอายุถึง supportUntil ส่วนลูกของตัวละครใช้รายได้ครัวเรือนและเงินสดของตัวละครจ่าย ไม่สร้างหนี้แยกให้ลูก

รายได้คู่สมรสเข้าครัวเรือนทุกปี หักค่าครองชีพคู่สมรสด้วย แม้ตัวละครจำคุกคู่สมรสยังทำงาน เงินเก็บส่วนตัวก่อนพบกันอาจตกทอดเมื่อเสียชีวิต (สุ่มตาม inheritanceChance) จึงไม่บวกรายได้ซ้ำเป็นมรดก พ่อแม่สะสมเงินเก็บจากส่วนที่เหลือและหยุดรายได้เมื่อเสียชีวิต มรดกอาจไม่มีและจ่ายครั้งเดียว

แก้ config แล้วเพิ่ม revision เป็นเลขใหม่ เริ่มชีวิตใหม่เสมอ รีสตาร์ต dev server; สำหรับ production ต้อง build และเปิด server ใหม่ Config ถูกอ่านตอน build ไม่ใช่ระบบแก้สดระหว่างเล่น แชร์ที่ revision ต่างกันจะถูกปฏิเสธ เซฟเดิมไม่รองรับ

ใช้ค่าที่ไม่ติดลบ โอกาส/อัตราในช่วง 0–1 จำนวนปีผ่อนเป็นจำนวนเต็มอย่างน้อย 1 ดอกเบี้ยผ่อนต้องมากกว่า 0 และเงินดาวน์น้อยกว่า 1

## v6

- life.averageLifespan: อายุอ้างอิงของเส้นความเสี่ยงเสียชีวิต (ค่าเริ่มต้น 78) ไม่ใช่อายุรับประกัน; สุขภาพ อุบัติเหตุ สารเสพติด และคุกทำให้อายุจริงแตกต่างกัน
- life.maxAge: อายุสูงสุดของเกม; life.prisonDeathRisk: ความเสี่ยงเพิ่มขณะจำคุก
- health: ความถี่เหตุวิถีชีวิต เกณฑ์เข้าโรงพยาบาล และความเสี่ยงจากการพึ่งพาสารรุนแรง
- investment: สุ่มรอบรายงานจาก intervals และตัวคูณผลตอบแทนรายปีของ fund / stock / crypto
- dark.promotionHeat: ค่าตำรวจจับตาที่เพิ่มเมื่อสายมืดเลื่อนตำแหน่ง

พ่อแม่ช่วยค่าครองชีพและลูกจนเริ่มงานครั้งแรก หลังจากนั้นแม้ตกงานก็รับผิดชอบเอง รายได้พ่อแม่ไม่พอจึงใช้เงินเก็บและส่งยอดขาดให้ตัวละคร การล้มละลายยึดทุกสินทรัพย์และเงินสด ทำให้อยู่ข้างถนน จ่ายเริ่มเช่าห้อง 12,000 บาทเพื่อฟื้นตัวได้

รถหลักและรถเพิ่มเติมรวมกันสูงสุด 3 คัน ค่าดูแลและงวดคิดทุกคัน โบนัสความสุขจากการมีรถไม่คูณจำนวนคัน รายงานพอร์ตเป็นผลสะสม: มูลค่าปัจจุบัน + เงินขายคืน − เงินลงทุนสะสม รวมการสูญเสียพอร์ตจากการยึดทรัพย์ด้วย

ข้อมูลลูกมี id, parentSeed, เพศ สีผิว นิสัย และปีเกิด เตรียมไว้สำหรับเล่นต่อรุ่นลูกในอนาคต ยังไม่มีปุ่มสลับเล่นเป็นลูกในรุ่นนี้ เพลงธีมเป็นทำนองสังเคราะห์ด้วย Web Audio เปิด–ปิดผ่านปุ่มโน้ตเพลง และหยุดเล่นเมื่อซ่อนหน้า

## v7: เหตุการณ์ตามวัยและการเรียน

เงินสดแรกเกิดเป็น 0 และไม่มีเงินแจกจากรายได้พ่อแม่ เงินรางวัล/มรดกก่อนงานแรกเก็บใน heldMoney แล้วโอนเมื่อเริ่มงาน ค่าเรียนที่มีค่าใช้จ่ายใช้เงินเก็บพ่อแม่ก่อนเงินสดตัวละคร

events.randomChance = 0.28 (เดิม 0.08), cooldownYears = 1 (เดิม 3), layoffChance = 0.045 โอกาสรายปีที่มีงาน เหตุการณ์สำคัญตามวัยและตำรวจยังมาก่อนเหตุสุ่ม ตรวจสุขภาพก่อนเหตุทั่วไป: อายุ 18–19 = 14%, 20–40 = 48%, หลัง 40 = 58% ในปีที่ไม่มีเหตุสำคัญแทรก ช่วงอายุแก้ใน health.ts ส่วนอัตราแก้ใน config

education.matchingCareerBonus = 25 จุดเปอร์เซ็นต์ relatedCareerBonus = 10 ใช้ทั้งงานแรกและเปลี่ยนงาน โดยยังจำกัดโอกาสสูงสุด 95% การเรียนที่ยังสมัครไม่สำเร็จไม่ได้โบนัส เส้นทางเรียน–อาชีพอ่านได้ใน lib/game/journey/education.ts

เพิ่มเหตุการณ์ใหม่ 24 แบบใน extra-stories.ts มีอายุขั้นต่ำ/สูงสุดและตัวเลือกเฉพาะ 5 ข้อ เรื่องโปรเจกต์ธุรกิจใช้เฉพาะผู้ใหญ่ เด็กพบเรื่องโรงเรียนและครอบครัว รายงานพอร์ตเก็บจุดกำไรสุทธิรายปีจริง ไม่ใช้ยอดเติมเงินวาดเป็นกำไร ฉากประกอบและสาเหตุการเสียชีวิตบันทึกไปกับเรื่องราว

## v8: เงินส่วนตัวตั้งแต่เริ่ม

กติกานี้แทนระบบเงินวัยเด็กก่อนหน้า: family.initialMoney กำหนดเงิน 20,000 / 80,000 / 200,000 ตามรายได้ครอบครัวรวม ต่ำกว่า 330,000 / ต่ำกว่า 420,000 / ตั้งแต่ 420,000 บาทต่อปี เงินเป็นของผู้เล่น ใช้จ่ายค่าเรียนและทุกตัวเลือกโดยไม่ดึงเงินพ่อแม่ ไม่มีเงินเพิ่มรายปีอัตโนมัติ ไม่คิดค่าครองชีพและลูกก่อนงานแรก และไม่ส่งยอดขาดของพ่อแม่ให้ผู้เล่น ค่าใช้จ่ายที่เลือกเอง ค่ารักษา และภาระทรัพย์สินยังต้องจ่าย

เงินรางวัล อั่งเปา และมรดกเข้ากระเป๋าทันที ไม่มีบัญชีพักเงินรอเริ่มงาน events.redEnvelopeChance กำหนดโอกาสอั่งเปารายปีที่ไม่มีเหตุสำคัญแทรก family.redEnvelope กำหนดช่วงวัยและจำนวนเงิน รับได้ครั้งเดียวต่อเหตุการณ์ เงินเก็บพ่อแม่แยกไว้สำหรับข้อมูลครอบครัวและมรดก
