# ปรับสมดุลเกม v6

แก้ไฟล์ game-balance.json ในโฟลเดอร์นี้ ตัวเลขเงินใช้บาท/ปี อัตราใช้ทศนิยม เช่น 0.12 = 12%

- dark: เงินเดือนสองสายมืด, ความร้อนที่เพิ่มต่อปี, โอกาสบุกค้นสูงสุด, น้ำหนักค่าสัมพันธ์ในการต่อรอง (0.45 = สัมพันธ์ 100 เพิ่มโอกาส 45 จุดเปอร์เซ็นต์ ก่อนจำกัดเพดาน 95%)
- family: อายุสิ้นสุดการเลี้ยงดู, ค่าเลี้ยงดูลูก, ค่าครองชีพพ่อแม่, อัตราเก็บเงิน, เงินตั้งต้น, โอกาสมรดก, ช่วงรายได้และเงินเก็บคู่ชีวิต, อายุเสียชีวิตพ่อแม่ และความเสี่ยงเสียชีวิตคู่ชีวิต
- assets: ราคาบ้าน/รถทุกแบบ, เงินดาวน์ ดอกเบี้ย ระยะผ่อน ค่าดูแล, โบนัสสุขภาพ/สุขรายปี, ค่าซ่อมเทียบราคาซื้อ และโอกาสข้อเสนอ/เสียหาย

โอกาสเหตุทรัพย์สินเป็นโอกาสในปีที่มีสิทธิ์ตรวจ: อายุ 18 ขึ้นไป ไม่อยู่ในคุก เว้นจากเหตุการณ์ล่าสุด 2 ปี และไม่มีเหตุสำคัญอื่นแทรก จึงไม่ใช่ความถี่รับประกันทุกปี

พ่อแม่ใช้รายได้หลังค่าครองชีพ จากนั้นเงินเก็บ เพื่อจ่ายค่าเลี้ยงดูจนตัวละครเริ่มงานครั้งแรก ส่วนขาดใช้เงินของลูกก่อน แล้วจึงลงหนี้ลูก หนี้วัยเด็กยังไม่คิดดอกเบี้ย/ทวงชำระจนอายุถึง supportUntil ส่วนลูกของตัวละครใช้รายได้ครัวเรือนและเงินสดของตัวละครจ่าย ไม่สร้างหนี้แยกให้ลูก

รายได้คู่สมรสเข้าครัวเรือนทุกปี หักค่าครองชีพคู่สมรสด้วย แม้ตัวละครจำคุกคู่สมรสยังทำงาน เงินเก็บส่วนตัวก่อนพบกันอาจตกทอดเมื่อเสียชีวิต (สุ่มตาม inheritanceChance) จึงไม่บวกรายได้ซ้ำเป็นมรดก พ่อแม่สะสมเงินเก็บจากส่วนที่เหลือและหยุดรายได้เมื่อเสียชีวิต มรดกอาจไม่มีและจ่ายครั้งเดียว

แก้ config แล้วเพิ่ม revision เป็นเลขใหม่ เริ่มชีวิตใหม่เสมอ รีสตาร์ต dev server; สำหรับ production ต้อง build และเปิด server ใหม่ Config ถูกอ่านตอน build ไม่ใช่ระบบแก้สดระหว่างเล่น แชร์ที่ revision ต่างกันจะถูกปฏิเสธ เซฟเดิมไม่รองรับ

ใช้ค่าที่ไม่ติดลบ โอกาส/อัตราในช่วง 0–1 จำนวนปีผ่อนเป็นจำนวนเต็มอย่างน้อย 1 ดอกเบี้ยผ่อนต้องมากกว่า 0 และเงินดาวน์น้อยกว่า 1

- investment: สุ่มรอบรายงานจาก intervals และตัวคูณผลตอบแทนรายปีของ fund / stock / crypto

## v7: เหตุการณ์ตามวัยและการเรียน

เงินสดแรกเกิดเป็น 0 และไม่มีเงินแจกจากรายได้พ่อแม่ เงินรางวัล/มรดกก่อนงานแรกเก็บใน heldMoney แล้วโอนเมื่อเริ่มงาน ค่าเรียนที่มีค่าใช้จ่ายใช้เงินเก็บพ่อแม่ก่อนเงินสดตัวละคร

education.matchingCareerBonus = 25 จุดเปอร์เซ็นต์ relatedCareerBonus = 10 ใช้ทั้งงานแรกและเปลี่ยนงาน โดยยังจำกัดโอกาสสูงสุด 95% การเรียนที่ยังสมัครไม่สำเร็จไม่ได้โบนัส เส้นทางเรียน–อาชีพอ่านได้ใน lib/game/journey/education.ts

เพิ่มเหตุการณ์ใหม่ 24 แบบใน extra-stories.ts มีอายุขั้นต่ำ/สูงสุดและตัวเลือกเฉพาะ 5 ข้อ เรื่องโปรเจกต์ธุรกิจใช้เฉพาะผู้ใหญ่ เด็กพบเรื่องโรงเรียนและครอบครัว รายงานพอร์ตเก็บจุดกำไรสุทธิรายปีจริง ไม่ใช้ยอดเติมเงินวาดเป็นกำไร ฉากประกอบและสาเหตุการเสียชีวิตบันทึกไปกับเรื่องราว

## v8: เงินส่วนตัวตั้งแต่เริ่ม

## Revision 11: ต่างประเทศและการกู้เพื่อทางเลือก

abroad.countries กำหนดประเทศ งานเฉพาะ เงินค่าย้าย ตัวคูณเงินเดือน และค่าครองชีพที่เพิ่มต่อปี; abroad.offerChance กำหนดโอกาสข้อเสนอในปีที่เข้าเงื่อนไข อายุ 23–59 ปี การศึกษาและทักษะส่งผลต่อโอกาสสมัครงานต่างประเทศ

การกู้ในตัวเลือกเพิ่มเฉพาะเงินที่ขาด ต้องยืนยันก่อนทุกครั้ง ยังตรวจเงื่อนไขอายุ ทรัพย์สิน และพักสิทธิ์กู้ตามเดิม ดอกเบี้ย 18% ต่อปี เริ่มชำระตั้งแต่อายุ family.supportUntil; choiceCredit.bankruptcyThreshold คือเกณฑ์หนี้หลังชำระที่จะทำให้ล้มละลาย หน้าต่างยืนยันเตือนเมื่อยอดกู้เสี่ยงเกินเกณฑ์

lottery.prize = 8,000,000 บาท และ lottery.chance = 0.02 ต่อการซื้อ เกณฑ์ถ้วยเพิ่มสองเท่า: อาชีพใช้จำนวนครั้งเลื่อนขั้นสะสม การเรียนรู้ใช้ผลรวมสองทักษะสูงสุด หนังสั้นเลือกเฉพาะเหตุการณ์สำคัญและเก็บประเทศ ณ เหตุการณ์นั้น

## Revision 12: รายจ่ายประจำและประกัน

หวย: lottery.annualCost คือรายจ่ายต่อปี เริ่มออกรางวัลปีถัดจากเปิดซื้อ; chance เริ่ม 2%, annualIncrease เพิ่ม 0.01 ต่อปีที่ซื้อ (1 จุดเปอร์เซ็นต์), maxChance เพดาน 1. ยกเลิกแล้วรีเซ็ต ไม่ออกผลซ้ำในปีเดียว พักซื้อระหว่างติดคุก

แผนประกันใน lib/game/ventures.ts: พื้นฐาน 3,000/ปี (อุบัติเหตุ60%, โรค40%, เสียชีวิต150,000), ครอบครัว8,000 (75%,60%,500,000), อุ่นใจสูงสุด18,000 (90%,80%,1,500,000). ไม่มีวงเงินค่ารักษาสูงสุดในกติกานี้ โรคร้ายแต่ละชนิดตั้ง canRecover=true เพื่อให้รักษาหายได้ในแบบจำลอง

ค่าครองชีพเริ่มหลังการศึกษา: มัธยม18, วิทยาลัย20, มหาวิทยาลัย22, แพทย์24 หรือเมื่อเริ่มงานก่อนหน้านั้น เปลี่ยนงานมีโอกาส60% ที่ข้อเสนอไม่น้อยกว่าฐานเดิมบวก5–25%; ข้อเสนออื่นไม่น้อยกว่า85%ของฐานเดิมหรือฐานอาชีพใหม่ ใช้ฐานที่รับจริงในการเลื่อนขั้นต่อไป

## ตั้งค่าฟอนต์ทั้งเว็บไซต์

แก้ไฟล์ typography.json แยกจากกติกาเกม:

- fontScale: ตัวคูณขนาดข้อความ UI ทั้งหน้าเกม เมนู ป๊อปอัป และหน้า ending; 1 = ขนาดเดิม, 0.9 = เล็กลง10%, 1.2 = ใหญ่ขึ้น20%, 0.6 = เล็กลง40%
- lineHeightScale: ตัวคูณระยะห่างบรรทัด; 1 = เดิม, 1.1 = เพิ่ม10%
- fontFamily: รายชื่อฟอนต์หลักแบบ CSS พร้อมฟอนต์สำรอง
- monospaceFontFamily: ฟอนต์ตัวเลข/ข้อความที่ใช้ monospace
- displayFontFamily: ฟอนต์ตกแต่งในตำแหน่งที่ใช้ serif
- fontStylesheetUrl: URL stylesheet ของฟอนต์ที่ต้องโหลด เช่น Google Fonts หรือ /fonts/fonts.css สำหรับไฟล์ใน public; ใช้สตริงว่างถ้าใช้ฟอนต์ระบบ ไม่ต้องโหลดไฟล์ภายนอก

เมื่อเปลี่ยนฟอนต์หลัก ให้เปลี่ยน fontFamily และ fontStylesheetUrl ให้ตรงกัน ค่าตัวคูณต้องเป็นตัวเลขมากกว่า0 ค่าเริ่มต้นคงขนาดและระยะบรรทัดเดิมทั้งหมด การเปลี่ยน config ใช้หลัง build/deploy ใหม่ ไม่กระทบเซฟชีวิต

ขอบเขต: config นี้ควบคุมข้อความ HTML ของ UI; ตัวอักษรที่วาดไว้ใน SVG ฉาก8bitและการ์ดภาพสำหรับแชร์ยังใช้สัดส่วนภาพเดิม เพื่อไม่ให้ภาพที่แคป/ส่งออกล้นกรอบ

## Revision 13: หวยเริ่ม1% และรีเซ็ตเมื่อถูกรางวัล

ค่าปัจจุบันใน game-balance.json หมวด lottery ใช้แทนตัวเลขหวยในหัวข้อเก่า:
- chance: 0.01 = โอกาสเริ่มต้น1% (รวมถึงเมื่อยกเลิกแล้วเปิดซื้อใหม่)
- annualIncrease: 0.002 = เพิ่ม0.2จุดเปอร์เซ็นต์ต่อปี เช่น 1% → 1.2% → 1.4%
- resetOnWin: true = เมื่อถูกรางวัลรีเซ็ตตัวนับปี ทำให้งวดถัดไปกลับไปค่า chance โดยยังซื้อรายปีต่อ; false = ไม่รีเซ็ตหลังชนะ
- maxChance: เพดานโอกาส, annualCost: ค่าหวยต่อปี, prize: เงินรางวัล

ข้อความในตลาดลงทุนและประวัติแสดงทศนิยมตาม config ไม่ปัดเหลือจำนวนเต็ม
