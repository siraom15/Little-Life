# ชีวิตจิ๋ว — เกมจำลองชีวิต

Next.js + React + TypeScript เกมภาษาไทยแบบมือถือ ใช้กรอบกว้างสูงสุด 480px ทั้งบนมือถือและคอม พื้นดำ/ฟ้ามืด ฟอนต์ Sarabun มีหัว (สำรอง Tahoma)

## เริ่มพัฒนา

- npm run dev — เปิดที่ http://127.0.0.1:3000
- npm run build — ตรวจ TypeScript และสร้าง production
- npm test — ทดสอบกติกา เซฟ และจำลองหลายชีวิต
- npm run format — จัดรูปแบบซอร์ส

## รูปแบบการเล่นปัจจุบัน: v4

เวลาเดินอัตโนมัติ 6 / 3 / 1 วินาทีต่อปี (เริ่มต้น 3 วินาที) หยุดเมื่อมีทางเลือก ป๊อปอัป หน้าตั้งค่า หรือออกไปดูคนรอบตัว/การเงิน ไม่มีการเลือกกิจกรรมประจำปี ไม่มีโหมดข้ามไปเฉพาะทางเลือก และไม่เร่งเวลาชดเชยเมื่อปิดแท็บ

เมนูล่างมี 4 ส่วน:

1. ชีวิต — ฉาก สถานะ เหตุการณ์ งาน/ทักษะ และบันทึกแบบพับได้
2. คนรอบตัว — พ่อ แม่ คู่ชีวิต ลูก รายได้ครอบครัวและความผูกพัน
3. การเงิน — เงินสด รายรับรายจ่าย หนี้ ลงทุน หวย ประกัน บ้านและรถ
4. ตัวฉัน — ตัวตนปัจจุบัน ทรัพย์สิน และการตั้งค่า/นำเข้า/ส่งออก

## กติกาสำคัญ

- เริ่มอายุ 0 และสุ่มครอบครัว/เพศ มีโรงเรียนให้เลือกอายุ 6 สายเรียนอายุ 13 และเส้นทางหลังเรียนอายุ 18
- ทักษะเฉพาะ: วิชาการ เทคโนโลยี ธุรกิจ สร้างสรรค์ สื่อสาร ดูแลผู้คน ทักษะงานเพิ่มจากประสบการณ์รายปี
- ดวง 0–100 เปลี่ยนรายปี เปอร์เซ็นต์บนตัวเลือกใช้สูตรเดียวกับตอนตัดสินผล: ฐาน + ทักษะเฉพาะ × 0.35 + สถานะที่ระบุ × 0.15 + (ดวง−50) × 0.3; บางทางเลือกความรักรวมความผูกพันด้วย จำกัด 5–95% ทางเลือกไม่สุ่มเป็น 100%
- 20 สายอาชีพ รวมการเมือง มาเฟีย และนายหน้าใต้ดิน มี 4 ระดับงาน เลื่อนขั้นเพิ่มรายได้ 35% ของฐาน เปลี่ยนงานได้เฉพาะเหตุการณ์ ไม่สามารถเลือกจากเมนูทั่วไป
- เหตุการณ์ทั่วไปสุ่ม 8% ต่อปีที่เข้าเงื่อนไข ตั้งแต่อายุ 6 และเว้นอย่างน้อย 3 ปีจากเหตุการณ์ก่อนหน้า การศึกษา/งานตามวัย/สรุปวัย/ครอบครัวและวิกฤตหนี้แยกจากโอกาสนี้
- เมื่อว่างงานมีโอกาสพบงานใหม่ 35% หลังห่างเหตุการณ์อย่างน้อย 2 ปี ก่อนวัยเกษียณ
- ทุกเหตุการณ์มีอย่างน้อย 5 ตัวเลือกเฉพาะเรื่อง แสดงราคาและโอกาสสำเร็จ ค่าใช้จ่ายจ่ายก่อนสุ่มผลและไม่คืนเมื่อพลาด
- สรุปช่วงวัยเป็นป๊อปอัปที่อายุ 6, 13, 18, 25, 40, 60, 80 ถ้ายังมีชีวิตอยู่
- พ่อแม่มีชื่อ อาชีพ รายได้และอายุ รายได้หยุดเมื่อเสียชีวิต ช่วยค่าใช้จ่ายช่วงที่ผู้เล่นยังไม่ถึง 18 ปี
- ความรักเชื่อมจากรู้จัก → คบ → แต่งงาน → มีลูก ความผูกพันได้รับผลจากความสุขและหนี้ สามารถแยกทางและพบคนใหม่ ลูกยังอยู่ในประวัติหลังเลิกรา
- ลูกมีชื่อและปีเกิด ค่าเลี้ยงดู 36,000/ปีต่อคนจนถึงอายุ 22

## การเงินแบบท้าทาย

กู้ครั้งละ 50,000 ได้ปีละครั้งตั้งแต่อายุ 18 วงเงินตามรายได้ (ขั้นต่ำ 50,000 สูงสุด 200,000) ต้องยืนยันหลังเห็นยอดหนี้และยอดจ่ายปีหน้า ดอกเบี้ยเกม 18% ต่อปี ขั้นต่ำ 20% ของยอดหลังคิดดอกเบี้ยหรือ 6,000 แล้วแต่จำนวนใดสูงกว่า แต่ไม่เกินหนี้ทั้งหมด

รายจ่ายที่เงินสดไม่พอจะกลายเป็นหนี้ ค้าง 2 ปีมีเหตุการณ์เจรจา/หาเงิน/ล้มละลาย ค้างครบ 3 ปีหรือยอดเกิน 350,000 ล้มละลาย: ยึดพอร์ตทั้งหมด เงินสดเหลือ 30% ล้างหนี้ ห้ามกู้ 8 ปี รายได้งานยังอยู่

ลงทุนกองทุน/คริปโตมีมูลค่าผันผวนรายปี ขายคืนได้ หวย 80 บาทปีละใบ (อายุ 20+) โอกาสรับ 4,000 บาท 2% ตัวสุ่มผูกกับ seed จึงโหลดเซฟเพื่อเปลี่ยนผลปีเดิมไม่ได้

ประกันพื้นฐาน 3,000/ปี จ่ายผู้รับผลประโยชน์ 150,000; ครอบครัว 8,000/ปี จ่าย 500,000 จ่ายเบี้ยตอนซื้อและต่อรายปี ถ้าเงินไม่พอกรมธรรม์สิ้นสุดก่อนตรวจเหตุปีนั้น ผลประโยชน์แยกจากเงินสดผู้เล่น กติกาทั้งหมดเป็นสมมติสำหรับเกม

## ส่วนขยาย v4: ชีวิตที่เห็นผลในฉาก

- เพิ่ม 11 อาชีพจากชุดก่อน รวม 20 สาย อาชีพเสี่ยงแสดงรายได้ โอกาสเข้าสายงาน และความเสี่ยงตำรวจ ทางเลือกงานพับเหลือ 5 ข้อแรก กดดูเพิ่มเติมเพื่อเลือกสายอื่นได้
- โอกาสมีลูกซ้ำตามวัย 30/34/38/42/46/50/54 และในเหตุการณ์สุ่มเมื่อแต่งงานแล้ว (สูงสุด 5 คน) โอกาสงาน/เลื่อนขั้นกลับมาได้หลายครั้งถึงวัย 63
- มาเฟีย/งานใต้ดินเพิ่มความร้อนปีละ 18 จุด ความร้อนทำให้เกิดเหตุบุกค้น มี 5 ทางเลือกรวมยื่นส่วย ซึ่งคิดเปอร์เซ็นต์ด้วยสูตรเดียวกับตัวเลขที่แสดง
- เมื่อจำคุก engine รับเฉพาะ action เดินปี ไม่มีคำสั่งเกมอื่น ฉากเปลี่ยนเป็นคุก ป๊อปอัปรอจนพ้นโทษ เวลาเดินต่อเอง เมนูซื้อขายถูกล็อก เมื่อออกจากคุกได้โอกาสหางานใหม่ทันที
- แชร์ชีวิตเป็นโหมดอ่านอย่างเดียวเสมอ รวมถึงช่วงติดคุก ไม่มีการเดินเวลาในหน้าของเพื่อน
- ซื้อกองทุน/คริปโตและขายคืนซ้ำได้ภายในปีเดียวกัน ซื้อแล้วขายในปีเดียวกันไม่ทำกำไรจากระบบ ไม่เปลี่ยนมูลค่าจนกว่าจะเดินปี
- บ้าน 5 แบบ: ห้องชุด 350,000 / ทาวน์เฮาส์ 650,000 / บ้านเดี่ยว 1,200,000 / บ้านสวน 2,200,000 / คฤหาสน์ 5,000,000
- รถ 5 แบบ: มอเตอร์ไซค์ 45,000 / รถเล็ก 280,000 / ซีดาน 650,000 / SUV 1,100,000 / สปอร์ต 3,500,000
- ซื้อสดหรือผ่อน: บ้านดาวน์ 20% ดอกเบี้ย 6% ต่อปี 15 ปี; รถดาวน์ 25% ดอกเบี้ย 8% ต่อปี 5 ปี ค่างวดเป็นสูตรลดต้นลดดอกแบบรายปี ปัดเป็นบาทและเผื่อเศษปัดเพื่อปิดหนี้ในกำหนด งวดสุดท้ายเก็บเฉพาะยอดจริง
- ภาระผ่อนบ้านและรถรวมไม่เกิน 45% ของรายได้งาน ค่าดูแลบ้าน 1%/ปี รถ 4%/ปี บ้านลดค่าที่พัก 36,000/ปีตั้งแต่วัยทำงาน ขาดส่งครบ 3 ปีถูกยึด ส่วนต่างกลายเป็นหนี้ทั่วไป
- ขายได้ที่ 60% ของราคาซื้อ หักยอดผ่อนก่อน หากมีส่วนต่างติดลบต้องมีเงินพอปิด บ้านและรถแสดงด้วย sprite ตามรุ่นในฉาก
- เมื่อล้มละลาย บ้าน รถ และพอร์ตถูกยึดด้วย หนี้ทุกก้อนถูกล้างตามกติกาเกม
- งานศพสุ่มรายชื่อผู้มาร่วมจากพ่อแม่ คู่ชีวิต ลูก เพื่อน และคนที่เกี่ยวข้องกับอาชีพ มีฉากพิธีและรายชื่อในบทสรุป เงินสุทธิประเมินบ้าน/รถที่ราคาขาย 60% หักหนี้คงเหลือ
- UI โอกาสแสดงเพียงตัวเลข % ไม่มีข้อความผลแน่นอน/ไม่มีการสุ่ม เพิ่มเป้าหมายสะสมบ้านรถและสีฟ้าเขียว–ทองบนพื้นมืด

ไฟล์ใหม่: assets.ts (ซื้อขาย/ผ่อน), police.ts (เหตุการณ์ตำรวจและโทษ), funeral.ts (ผู้ร่วมงาน); ทั้งหมดอยู่ใน lib/game/journey ส่วนภาพใช้ PropertySprites, PrisonScene, FuneralScene และหน้าร้าน/โปรไฟล์ใช้ AssetShop, SelfScreen

npm test รันเฉพาะ journey.test.ts และ expansion.test.ts รวมการจำลองเต็มชีวิต 100 รอบ ไม่รันชุดทดสอบกติกาเก่าที่จำลองหลายร้อยรอบ รอบนี้ไม่เปิดตรวจ UI ตามข้อกำหนดเดิม

## v5: ครัวเรือนและทรัพย์สิน

ปรับสมดุลได้ที่ `config/game-balance.json` ดูคำอธิบายและวิธีนำไปใช้ใน `config/README.md` เพิ่มเงินเดือนสายมืด ลดโอกาสบุกค้น เพิ่มค่าสัมพันธ์ช่วยต่อรอง พ่อแม่รับผิดชอบค่าเลี้ยงดูก่อน คู่สมรสมีรายได้และค่าครองชีพ มรดกอาจมีหรือไม่มี บ้านและรถให้โบนัสประจำปีพร้อมเหตุเสียหาย/ข้อเสนอซื้อ มีสีและเครื่องหมายเงินเข้าออก รุ่นนี้เริ่มเซฟใหม่และแยกตาม revision ของ config

## v6: เส้นทางชีวิต

เพิ่มมหาวิทยาลัย 8 ทางเลือก ตำแหน่งเฉพาะและทางเลื่อนขั้น 3 แบบต่ออาชีพครบ 20 อาชีพ เกษียณและภารกิจเฉพาะงาน ลูกมีตัวตนและฉากเกิด ลงทุนกองทุน/หุ้น/คริปโตหลายขนาดพร้อมรายงาน 2/3/5 ปี โรงรถ 3 คัน สุขภาพและการพึ่งพาสาร โรงพยาบาล ความเสี่ยงเสียชีวิตในคุก และชีวิตข้างถนนพร้อมทางฟื้นตัว ฉากสะท้อนฐานะและสถานะ ปุ่มพิกเซลและเพลงธีมเปิด–ปิดได้ กติกาใหม่ใช้เซฟ v6

## v7: เรื่องราวตรงช่วงวัย

เงินสดเริ่มที่ 0 ไม่มีเงินแจกก่อนงานแรก ค่าเรียนใช้เงินพ่อแม่ การศึกษาตรงสายเพิ่มโอกาสได้งาน เพิ่ม 24 เหตุการณ์ตามวัยและโอกาสเลิกจ้าง สุขภาพเกิดบ่อยขึ้นตั้งแต่อายุ 20 ปี ฉากหลุมศพ/เลื่อนขั้น/กราฟพอร์ตจริง/ไฟไหม้แยกตามเหตุการณ์ และระบุสาเหตุเสียชีวิตชัดเจน เริ่มเซฟใหม่ในรุ่น v7
